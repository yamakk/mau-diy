# 自律的情報技術学習演習

## 📋 前半課題

AWS Amazon EC2をつかったWebサーバの構築と公開 (2日間)

参加者1人ずつ以下の作業を情報技術を利用し自力で達成する

- EC2インスタンスの作成とSSHログイン
- EC2 Amazon Linuxの設定
- Webサーバ(Apache)のインストールと設定
- 並行して[Markdown形式](https://ja.wikipedia.org/wiki/Markdown)で作業記録を作成
- 作業記録をhtmlに変換し, EC2上のWebサーバで公開
- SlackにURLを提出

作業記録のWeb公開が達成できない場合は基本的に不合格となります

## 🎯 基本方針
この授業では, 技術そのものではなく「技術の学び方」を身につけることを重視します

Webサーバについての授業ではなく、さまざまな技術の学習に共通する問題解決プロセスと自律的な試行錯誤を経験します

自律的な試行錯誤を目的とするため, 不具合, エラーなどを自力で解決することを基本姿勢とします
講師, TAはこの資料に記載した内容にそって助言を行います

## ⚠️ 授業前の注意事項

### AWS(Amazon Web Services)利用について
- クレジットカードが必要です (授業前に連絡済み)
- 無料枠（12ヶ月）を使用します
  - 無料期間終了後の課金目安：t4g.nano インスタンス：約450円/月
  - 各自課金の仕組みについて調べてください
- 代替環境：SSHをつかってLinuxをroot権限で扱え, Webサーバ構築・公開が可能であればAWS以外でも構いません

## 📊 評価項目

A技術的評価項目 と B学習姿勢・問題解決プロセスを総合的に評価します

### A. 技術的評価項目 - 必須

#### Webサーバの構築と公開
以下の工程を情報技術を利用しつつ自力で達成する

- EC2インスタンスの作成とSSHログイン
- EC2 Amazon Linuxの設定
- Webサーバ(Apache)のインストールと設定
- 並行して[Markdown形式](https://ja.wikipedia.org/wiki/Markdown)で作業記録を作成
- 作業記録をhtmlに変換し, EC2上のWebサーバで公開
- SlackにURLを提出

作業記録のWeb公開が達成できない場合は基本的に不合格となります

#### 経験者の課題

すでに経験したことのある参加者はWebサーバ構築後, これらの技術が関わるまだ取り組んだことのない内容を講師と相談して設定する

過去の事例：

- Ansibleでの環境自動構築
- DockerによるWebサーバ環境構築
- Firebaseとの比較
- Python+cronによるデータスクレイピングと公開
- データベース構築とD3.jsによるデータビジュライズ
- ハニーポットによる不正侵入観察

### B. 言語化・問題解決の姿勢

#### B-1. 作業記録・言語化
- 事前アンケートの意図を理解して言語化できているか
- 講師や他の参加者と積極的にコミュニケーションがとれているか
- わからないなりにいまの理解で言語化する努力が見られるか
- Markdown形式での適切な記録ができているか
  - コードハイライト, リンクなどを適切に使用しているか
  - エラーの記録, 仮説, 対処, 結果などが含まれているか
  - **自分にとって後から読みやすく整理されているか**

#### B-2. 問題解決の姿勢
- 大きな課題を小さなステップに分解し段階的に進めているか
- エラー, 不具合で思考停止せず別の方法を試しているか
- 関係ないところを潰す消去法的な試行錯誤が見られるか
- 公式ドキュメント, 検索, LLMなどの情報源を活用しているか
- 情報源の信頼性の違いを意識してリサーチが行えているか

## 🌱 参考事項

### 認知負荷を下げる環境

- ハードウェア: 画面配置, 外部ディスプレイ
- OS: キーリピート速度, ジェスチャ, ショートカット
- アプリケーション: 記録・検索・要約 ノートテイキング,  シンタックスハイライト
- 特にUnix Shell環境でのTAB, 上下キー, 検索, コピペ

### 思考停止を防ぐ

- 実行前に得られる結果の仮説を立てる
- 消去法で試行錯誤する👉️問題の原因を一発で解決できることは稀
- 手を動かして新しい手がかりを探す
- 小学生に説明するつもりで言語化する [Rubber Duck Debugging](https://ja.wikipedia.org/wiki/%E3%83%A9%E3%83%90%E3%83%BC%E3%83%80%E3%83%83%E3%82%AF%E3%83%BB%E3%83%87%E3%83%90%E3%83%83%E3%82%B0)
- 賢い質問を意識する [賢い質問のしかた](https://www.ranvis.com/articles/smart-questions.ja.html#classic)

### Yak Shaving対策
[Yak Shaving](http://0xcc.net/blog/archives/000196.html)：問題解決中に本来の目的から逸れて, 関連する別の作業に没頭してしまうこと 

- ポモドーロメソッド（25分単位）で作業する
- 作業の目的を言語化, 文章化, 階層化する
- 作業記録にタイムスタンプをつける

### 学習姿勢

- 同じ課題に対する多様な取り組み, 試行錯誤を自分と比較する
- 消費者から抜け出す覚悟を決める👉️コンピュータは家電ではない
